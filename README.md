# Pygame Movement & Obstacle Test

A simple 2-player movement test built with Python and Pygame.

⋆.𐙚 ̊ How to Play

Two sprites appear on a 700x500 screen. You can move them independently, but they cannot pass through the gray walls or the screen edges.

⋆.𐙚 ̊ Player 1 Controls (WASD) 
 
- Use W to move up

- Use A to move left

- Use S to move down

- Use D to move right

⋆.𐙚 ̊ Player 2 Controls (Arrow Keys)

- Use Up Arrow to move up

- Use Left Arrow to move left

- Use Down Arrow to move down

- Use Right Arrow to move right

⋆.𐙚 ̊  Requirements

You need to have Python and the Pygame library installed.

    pip install pygame

⋆.𐙚 ̊  Setup

Copy the repo. Then, Place the three assets in the same folder:

- background.png (700x500)

- sprite1.png (100x100)

- sprite2.png (100x100) 

Run the script:

    python catch_up.py
